# Portfólio de Tiago Augusto

React, TypeScript e Vite. Tema escuro com destaque em ciano, responsivo e preparado para GitHub Pages.

## Desenvolvimento

Requer Node.js 22.12 ou superior.

```sh
npm install
npm run dev
```

## Validar e visualizar a versão de produção

```sh
npm run build
npm run preview
```

## GitHub Pages

1. Envie o projeto para um repositório no GitHub, na branch `main`.
2. Em **Settings > Pages > Source**, selecione **GitHub Actions**.
3. O workflow de publicação executa a cada push em `main` ou manualmente na aba Actions.

O caminho base relativo do Vite permite hospedar no endereço de um repositório ou em um domínio próprio. A navegação usa âncoras e não depende de redirecionamento de rotas.

## Conteúdo

Edite `src/App.tsx` para atualizar apresentação, tecnologias, experiência e contato. O currículo está em `public/curriculo.pdf`. Os projetos aguardam informações reais e os links de GitHub e LinkedIn serão adicionados quando fornecidos. O período da BSA Tech foi reproduzido como informado no currículo: 2021–2026.

As fontes são carregadas do Google Fonts e possuem alternativas locais. Endereço residencial e telefone não são exibidos na página. Revise o currículo PDF antes da publicação: ele contém os dados de contato originais.
